# RecipeHub

Учебный итоговый проект на React + Vite.

## Запуск

1. Установите Node.js (рекомендуется LTS).
2. Распакуйте архив.
3. Откройте папку `recipehub` в VS Code.
4. В терминале выполните:

```bash
npm install
npm run dev
```

5. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Для проверки production-сборки: `npm run build`.

## Что реализовано

- Регистрация и вход (демо-аутентификация), выход.
- AuthContext и ProtectedRoute.
- Роль пользователя `user`.
- Каталог рецептов из публичного DummyJSON API.
- Поиск и фильтр по категории, состояния loading/error/empty.
- Страница рецепта по URL-параметру.
- CRUD собственных рецептов: создание, просмотр, редактирование, удаление.
- Избранное.
- Профиль пользователя.
- Сохранение пользователей, сессии, собственных рецептов и избранного в localStorage.
- React Router, useState, useEffect, useContext, props, map и key.

## Важное ограничение для защиты

DummyJSON используется как внешний API-витрина. Он имитирует POST/PUT/DELETE, но не хранит изменения постоянно. Поэтому каталог API только читается, а собственные рецепты и аккаунты сохраняются в `localStorage` браузера. Это постоянное локальное хранилище для демонстрации, но не полноценная серверная база данных. Для реального публичного сервиса потребуется backend и база данных.

Аутентификация здесь учебная: пароль хранится в localStorage без серверного хеширования. Не используйте реальные пароли. Если преподаватель требует серверную БД, замените учебный слой хранения на backend (например, Express + SQLite/PostgreSQL).

## API

`GET https://dummyjson.com/recipes?limit=30`

Запрос выполняется в `src/pages/ApiPage.jsx` и `src/pages/HomePage.jsx`. Его можно увидеть в DevTools → Network.
